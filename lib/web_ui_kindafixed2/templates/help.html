What is SYNTRAF?

SYNTRAF (Synthetic Traffic) is a tool for generating synthetic network traffic to measure Quality of Experience (QoE). It creates mesh topologies of UDP traffic between nodes using iperf3, with centralized configuration management, InfluxDB for metrics storage, and Grafana for visualization.

Quick Start
  1. Server Setup: Configure a SYNTRAF server with the [SERVER] section in your config file
  2. Add Databases: Configure InfluxDB connections in [[DATABASE]] sections
  3. Create Mesh Groups: Define test profiles in [[MESH_GROUP]] sections
  4. Add Clients: Define client nodes in [[SERVER_CLIENT]] sections
  5. Deploy Clients: Install SYNTRAF on client machines and configure them to connect to the server
Command Line Usage
python3 syntraf.py -c /path/to/config.toml -l /path/to/logs/

{{ _('help.faq') }}

For G.711 VoIP simulation, use these settings in your MESH_GROUP:

BANDWIDTH = "87.2K"
PACKET_SIZE = "218"

218 bytes = 18 (Ethernet) + 20 (IP) + 8 (UDP) + 12 (RTP) + 160 (voice payload) @ 50 pps = 87.2 Kbps

Server:

TCP 6531 (control channel)

Clients:

UDP/TCP 15000-16000 (iperf3 listeners)

{{ _('help.troubleshooting') }}

IPERF3: ERROR - TEST AUTHORIZATION FAILED
  • Clock skew between nodes exceeds 10 seconds - synchronize time using NTP
  • Increase IPERF3_TIME_SKEW_THRESHOLD if time sync is not possible
libuv timer resolution warning

This warning is harmless and appears on Windows due to gevent/libuv limitations.

safe_join deprecation error

Pin Flask to version 2.0.3: pip install Flask==2.0.3
