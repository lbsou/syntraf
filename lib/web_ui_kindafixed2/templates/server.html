Certificates

Use certificates signed by your certificate authority: generate a signing request (CSR), have it signed, then upload the signed certificate with its chain. The private key is created on this server and never leaves it. Installing a certificate takes effect after a server restart.

Syslog forwarding (SIEM) live

The server's own logs, and those its clients send it (the client is then the syslog host). Messages at or above the minimum level and the server log level. Sent from a bounded queue: an unreachable collector never slows SYNTRAF; messages it cannot take are counted as dropped. With UDP, “sent” does not mean received.
