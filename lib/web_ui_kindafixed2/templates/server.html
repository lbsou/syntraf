Forward to a syslog collector (SIEM) live

The server's own logs, and those its clients send it (the client is then the syslog host). Messages at or above the minimum level and the server log level. Sent from a bounded queue: an unreachable collector never slows SYNTRAF; messages it cannot take are counted as dropped. With UDP, “sent” does not mean received.
